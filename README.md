Java was made in 1995 by one James Gosling and his team at Sun Microsystems basically because they were frustrated that code written in languages like C++ would only work on one operating system and not another. They wanted to create something simpler that could run on any device without having to rewrite everything, which is where the famous "Write Once, Run Anywhere" idea came from
a brief history of java is that Java was first built for things like interactive TV and small embedded devices, but that didnt really take off so they pivoted when the interet started blowing up in the 90s and it turned out Java was perfect for it. By the late 90s and 2000s it became one of the most popular programming languages on the planet, used everywhere from websites to banking software to Android apps. Oracle bought the company that owned Java back in 2010 and they still run it today, continuing to update it regularly
